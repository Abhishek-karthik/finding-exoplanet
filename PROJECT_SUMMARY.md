### Description:
```
🔭 Machine Learning classifier that predicts whether distant stars have exoplanets using NASA's Kepler Space Telescope data.

✨ Features:
• Implements Transit Method for exoplanet detection
• Data normalization (mean normalization technique)
• FFT feature engineering for frequency analysis
• SMOTE data balancing for imbalanced classes
• Random Forest Classifier with 50 decision trees
• Complete Jupyter notebook with explanations

📊 Dataset: Kepler exoplanet observations (5000+ training samples)

🎯 Objective: Binary classification - identify stars that host exoplanets

🔬 Technologies: Python, Pandas, NumPy, Scikit-learn, Imbalanced-learn, Matplotlib

📚 Educational project demonstrating machine learning pipeline from data preprocessing to model evaluation.
```
